# Piano

## 專案介紹

本專案為一個簡易電子琴，並且提供錄音撥放功能，內建一首**小星星**

## 操作步驟

1. 點擊琴鍵，對應的音符將會發出聲響
2. 點擊開始錄音，可以將您所按的音符記錄下來
3. 點擊停止錄音，錄音停止
4. 點擊播放，播放您錄音的內容
5. 點擊**小星星**，即會撥放小星星
